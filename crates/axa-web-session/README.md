# axa-web-session

Web sessions for Axum services over [`axum_session`](https://crates.io/crates/axum_session), with safe defaults, from the [axa](https://github.com/publicprojects-io/axa) family.

Enable it through the `session` feature of `axa`, or depend on this crate alone. See the crate documentation for usage.
