# axa-openapi

Serve OpenAPI documents and a pinned Swagger UI from Axum services, from the [axa](https://github.com/publicprojects-io/axa) family.

It works with a document generated by `utoipa` or one written by hand. The
Swagger UI page loads one exact version from a CDN with an integrity hash, so
the browser refuses any script that has changed.

Enable it through the `openapi` feature of `axa`, or depend on this crate alone.
See the crate documentation for usage.
