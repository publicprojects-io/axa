# axa-pagination

Offset pagination, count headers, and LIKE escaping for Axum services, from the [axa](https://github.com/publicprojects-io/axa) family.

Enable it through the `pagination` feature of `axa`, or depend on this crate alone. See the crate documentation for usage.
