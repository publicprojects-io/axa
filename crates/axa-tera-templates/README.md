# axa-tera-templates

Tera templates with safe escaping and generic errors for Axum services, from the [axa](https://github.com/publicprojects-io/axa) family.

HTML escaping is on by default, and a template failure is logged rather than shown
to the visitor.

Enable it through the `tera` feature of `axa`, or depend on this crate alone.
See the crate documentation for usage.
